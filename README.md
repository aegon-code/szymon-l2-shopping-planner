# Szymon Guild Shopping Planner
เปิด index.html เพื่อใช้บนเครื่อง หรือนำไฟล์เว็บขึ้น static hosting ที่รองรับ HTTPS เพื่อให้สมาชิกเปิด Share Link ได้จากทุกเครื่อง

## การแก้ไขร้านค้า
แก้ items.js โดย price คือ SG ต่อหน่วย และ qty คือจำนวนแนะนำ ใช้ limit เฉพาะเพดานที่ยืนยันแล้ว รายการที่ไม่ทราบให้ใช้ null และ rule เป็นข้อความแสดงเงื่อนไขหรืออายุใช้งาน

เพิ่มไอเทมโดยคัดลอกรายการเดิมแล้วใช้ id ใหม่ ห้ามนำ id เก่ามาใช้แทนไอเทมอื่น เพราะ id เชื่อมกับแผนที่บันทึกไว้ ใส่ category 0 สำหรับ Coin & Package, 1 สำหรับ Inventory, 2 สำหรับ Premium, 3 สำหรับ Agathion หรือ 4 สำหรับ Rune เพิ่มภาพในโฟลเดอร์เดียวกับ index.html และจับคู่หมายเลขใน icon-map.js เว็บใช้สัญลักษณ์หมวดแทนรายการที่ไม่มีภาพ ยอดแผนและกราฟคำนวณจากข้อมูลทันที
ฟังก์ชัน setBuild ใน app.js จัดการ preset และตัวเลือกอยู่ใน index.html

## การใช้งาน
แต่ละเบราว์เซอร์บันทึกแผนแยกกัน ผู้ใช้เลือกไอเทมและปรับจำนวนตามแผน กรอกจำนวนที่ซื้อจริงในช่องซื้อแล้ว เมื่อยกเลิกไอเทมที่ซื้อแล้ว ประวัติใช้เงินจริงยังคงอยู่ ปุ่มรีเซ็ตจึงขอคำยืนยันก่อนล้างประวัติ เปอร์เซ็นต์ความคืบหน้าคิดตามมูลค่า SG ที่ซื้อครบตามแผน อัตราเงินบาทกรอกเป็นบาทต่อ 1 SG
ลิงก์แชร์เก็บสำเนาแผน ณ เวลาที่คัดลอก รวมงบส่วนตัวและจำนวนที่ซื้อแล้ว ผู้รับต้องกดนำแผนนี้ไปใช้และยืนยันเพื่อแทนแผนเดิม
